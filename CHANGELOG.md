# Changelog

## v1.0.1

**English:** The power chart now holds the last reported PV, home, grid, battery and EV charging value until the next reading. In particular, an idle charger stays at 0 kW until charging actually begins. The solar forecast still uses linear interpolation.

**Deutsch:** Das Leistungsdiagramm hält den letzten gemeldeten Wert für PV, Haus, Netz, Batterie und Ladepunkt bis zur nächsten Messung. Ein inaktiver Ladepunkt bleibt dadurch bis zum tatsächlichen Ladestart bei 0 kW. Die PV-Prognose wird weiterhin linear interpoliert.
